# Nanka Hair Studio

Strona internetowa salonu fryzjerskiego Nanka Hair Studio.

## Uruchomienie
npm install
npm run dev

## Wdrożenie
Projekt jest przygotowany pod Vercel i Next.js.

## Panel właściciela
Kolejny etap: bezpieczny panel administracyjny z logowaniem, usługami, cenami, godzinami, galerią i rezerwacjami.
